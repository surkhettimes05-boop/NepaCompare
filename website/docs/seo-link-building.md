# Legitimate link-building plan

No links should be bought, exchanged at scale, hidden in widgets, or placed through automated comments. Outreach should lead with a genuinely useful source-backed resource.

## Linkable assets now available

- `/motor/insurers` — regulator-sourced directory of Nepal's listed non-life insurers.
- `/motor/plans` — source library summarizing only claims on official insurer pages.
- `/blog` — 12 cited motor-insurance guides.
- `/np/motor` — Nepali motor-insurance explainer.
- `/editorial-policy` — public sourcing and corrections standard.

## Outreach targets

1. Insurers whose official pages are cited: request factual corrections and permission to reference their current policy wording.
2. Nepalese automobile associations, clubs and road-safety groups: offer the accident and renewal checklists as public resources.
3. Vehicle dealers and EV owner communities: share the EV coverage-question checklist without requesting keyword-rich anchor text.
4. Consumer education, finance and technology publications in Nepal: pitch original analyses derived from Nepal Insurance Authority public datasets.
5. Universities and financial-literacy programs: offer bilingual guides for resource pages.

## Outreach workflow

1. Verify the organization and named recipient.
2. Read its existing resource page and identify one relevant asset.
3. Send one personalized message; do not use bulk automation.
4. Disclose NepaCompare's commercial status.
5. Ask for corrections first, a resource citation second.
6. Record contact, date, resource, response and resulting URL.
7. Follow up once after 7–10 business days, then stop.

## Suggested message

Subject: Source check for our Nepal motor-insurance guide

Hello [Name],

If the guide is useful to your customers or readers, you are welcome to include it in your public resources. There is no payment, reciprocal-link requirement or requested anchor text. Corrections can be sent to complaints@nepacompare.com.

Regards,
NepaCompare Editorial Team

## Search Console submission

After production deployment and canonical-domain configuration:

1. Verify the domain property in Google Search Console.
2. Submit `https://<canonical-domain>/sitemap.xml` under Sitemaps.
3. Inspect `/`, `/motor`, `/motor/insurers`, `/motor/plans`, `/blog`, `/np`, and `/np/motor`.
4. Request indexing only after each URL returns 200 with the intended canonical.
5. Monitor Page indexing, Core Web Vitals, HTTPS and Enhancements weekly for the first month.
